# Vimbre — frontend v0.1

A new Next.js + TypeScript frontend based on the approved light design and companion dark reference. Includes glass effects, backdrop blur, responsive layouts, an accessible theme switch, and nine screen types: landing, pricing, login, register, HR, Employee, Manager, Cover Person, AI Builder and Settings demo views.

## Running locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` and `http://localhost:3000/demo`.

**Important:** This is UI-only. Authentication, AI, emails, data saving and billing are disabled. Demo data are fictional. Never use it as a live employee record system before backend access control is built. PRD pricing must be confirmed before launch.
