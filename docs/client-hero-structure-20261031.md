# Hero and company structure display

Hero eyebrow: Work continuity for teams. Fixed headline word Understand; rotation: the why, the decisions, the full picture, the work. No quotation marks or Priorities. Reduced-motion and accessible pause behavior remain. Hero controls are Open workspace (workspace for a signed-in user, login otherwise) and See the walkthrough. Signed-in navigation uses Go to workspace, avoiding the duplicate label. Public metadata uses the same default headline.

The subline now describes the shipped controlled flow: bring in conversations from connected tools or paste them, review task/decision drafts, then keep work and context together. It does not promise automatic ingestion from every existing tool. OAuth connections still require configured providers, company permission and individual consent; no provider tokens or paid AI calls were used for this copy change.

The observed company has effective Business access but a separate legacy team_mode=small setup preference. This value is not the subscription or its seat limit. Company Settings and Departments now use one shared read-only company_workspace_structure summary from the authoritative billing_effective_plan. The checked RPC returns only plan and team_mode to active members of their own company; no customer IDs, codes, prices, invoices or other billing details. The UI shows Business · Departments optional, or Business · Departments when configured. The misleading Small team label/banner is removed. Free/Starter/Growth labels use the same source. Team mode, existing departments, invitation requirements, permissions and paid entitlements are unchanged; upgrades do not force department assignment or erase an existing structure.

Validation: 284 tests passed, AI/billing type checks and production build passed. Rollback SQL tested each active member against their own company, inactive/unauthenticated rejection, absent anonymous grant and the two-field response. No new security-advisor finding mentions the new functions. Actual landing page checked in 360px and 1366px preview frames; the longest rotating phrase fits the mobile hero. Preview files/config removed before release.
