# Handovers: final phase 1 and phase 2 brief

Client screenshots supplied 24 October 2026. Build the complete flow now; sudden absence, exit, external sharing and PDF export use server flags without redesign.

## Layout and copy

Title Handovers; “Pass your work on so nothing stops while you’re away.” Primary New handover; list type/dates/cover/status. Empty: “No handovers yet. Start one before you’re away.” Remove obsolete unavailability banners, redundant sidebar destinations and generic explanatory copy. Keep contextual links to a particular task/decision. Side panels need full-width controls, aligned labels, consistent spacing, readable structure and mobile padding. Settings has the same form treatment and no duplicate Team/Departments navigation.

## Four steps

1. Details: Planned leave, Exit or Sudden absence (latter two flagged); dates; cover required before submission; manager defaults to line manager. No health detail fields.
2. What to include: select role work, active decisions, contacts, documents, deadlines, own notes; choose open tasks individually; decisions can be marked Do not change; What comes first priorities and Watch outs. Use my role and records imports the selected confirmed content without AI.
3. Draft: Generate draft or Write manually; editable Summary, What comes first, Open tasks, Decisions to keep, Contacts, Documents, Dates, Watch outs, Notes. Keep What I handle content as a separate editable section too. Banner “Draft. Check before you submit.”
4. Review and submit: confirm cover/dates/priorities, then Submit to manager. Saving a draft does not submit it.

## Lifecycle

Draft, Submitted, Changes requested, Approved, Active, Completed (plus retained Cancelled legacy records). Manager receives notification and My day Waiting on you; approves or requests changes with a comment. Edits after approval are marked Changed since approval and notify the manager. Cover is notified on approval; reads the handover, sees selected tasks under Covering for, and can complete those tasks during cover dates. Task ownership remains with the original owner; Take back ends delegation and marks Completed. Cover-completed work stays in the record. While you were away summary runs only on request.

Phase 2: manager/admin sudden absence uses accessible role records, never the absent person's private notes or personal task bodies; exact banner “Created by manager. Not reviewed by owner.” Immediate cover visibility after the manager confirms. Exit includes explicit final role reassignment. External sharing is a read-only snapshot capability with expiry/revocation and no private source URLs. PDF export opens a print-ready document for the browser's Save as PDF workflow.

## Data and privacy

Stable role, owner/company/cover/reviewer; sectioned content, selected source task/decision IDs, creator, approval metadata, version history, status history and shares. Cross-company denial, current active accounts, department-scoped reviewer, explicit selected task cover access. No task ownership transfer or original Capture access. Old endpoint cannot bypass the structured workflow.
