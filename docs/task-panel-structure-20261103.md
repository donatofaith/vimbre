# Task panel structure

Task details now lead with title, Pin, status, due date, priority and optional time estimate. Notes and an optional checklist follow. Context, More options and Record start collapsed. More options mounts secondary tools on first expansion and keeps their drafts mounted when collapsed.

Existing source links, assignment, decisions, reminders, repeating tasks, files, comments, completion outcomes and activity history remain available. Editing leads with title, status, due date, priority and notes. Owner and additional fields sit in More options. Delete task is inside More actions, retaining existing deletion and confirmation behavior.

Task labels now say Pin, Unpin, Pinned and Unpinned, with a pushpin icon. Reward Stars retain their existing name. Existing database action and event keys are unchanged.

Validation: 358 tests passed; production build passed. Sample-data browser checks covered opening and closing task details, pin/unpin, secondary tools, editing, the deletion menu, mobile 360px and desktop 1440px, including dark mode.
