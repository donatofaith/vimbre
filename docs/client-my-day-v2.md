# My day work plan, client screenshots 22 October 2026

This client brief supersedes the earlier My day layout, filters and primary button choices. Preserve tasks, SQL actions status values, company isolation and roles. The founder display remains Super admin; no database role enum changes.

Greeting and a live workload line. Primary Use Vimbre AI; secondary Add a task and Capture an email or notes. Filters Today, This week, Overdue, All, Archived and department or external contact. List on mobile, Board on desktop, user choice preserved. Board To do, In progress, Done; done work is limited to seven days. Drag or keyboard status menu. Task cards show due date/time, source, department/contact and Remind me.

Task side panel: 24px heading, title, date chips Today/Tomorrow/Next week, optional time and searchable department/contact For. More options contains details, status, reminders, cover note, source link. No date autofocus, no assignment to other people. New tasks start To do. Plain end-user copy and external contact terminology.

AI input is pasted email/notes or explicit Suggest tasks for my role using Responsibilities, Open work and Recurring deadlines only. Draft cards require review and Save. Exact label Draft from Vimbre AI. Check before saving. No provider calls outside ai-run.

Recurring deadlines produce one task per cycle on that date in the owner's timezone, never backlog for past dates. Reminders are a bell and email at the selected time, then one check-in one hour after due time if incomplete. At most two alerts per due time. Done/Snooze/Not yet controls. Snooze and Not yet reset delivery timestamps; no manager escalation. Personal settings: email on/off, default 09:00, timezone Europe/London initially, UTC persistence.

Done opens Add to context, or queues it for the next My day visit after notification completion. Editable outcome draft may use Vimbre AI. User selects Decision log, Open work update or My notes, then Save. Explicit added tick; never save from clicking Add to context alone. Helper: Saves what you did and decided to your role record, so whoever covers can see it.

Every minute a scheduled processor creates due tasks and bell alerts, queues grouped reminder emails and dispatches through Brevo. Brevo replaces the brief's Resend reference because this project uses Brevo. Delivery activation requires a send-enabled Brevo key and verified sender; do not claim delivery until configured and tested.

New accounts see Get started first, returning users tasks first. Supplied reverse logo on navy without the white pill. Replace Company breadcrumb with actual company name. Respect reduced motion and mobile layouts. No timers/time tracking, subtasks, comments, task assignment, Gantt, invoicing, labels/colours or automation-rule builder.
